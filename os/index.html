作業系統博物館

這裡沒有截圖,也沒有影片。每一格都是一台 x86 電腦:CPU、記憶體、顯示卡、硬碟,全部在 WebAssembly 裡模擬,一條一條執行真正的機器碼。隨時可以換一台,離開時的進度會留在你的瀏覽器裡。

— MIPS 0 MB

使用說明

  • 滑鼠點一下畫面就會接管滑鼠和鍵盤;按 Esc 把滑鼠還給網頁。
  • 特殊鍵Ctrl + Alt + Del、Win、Alt + Tab 這類組合鍵會先被你自己的電腦攔走,改用下方的按鈕送進去。
  • 存檔換到另一台、切走分頁時會自動存檔,存在你的瀏覽器裡(IndexedDB),不會上傳。按「重新開始」就回到剛開機的樣子。
  • 網路這些電腦都沒有接上網際網路,瀏覽器打不開網頁是正常的。
  • 效能模擬一整台電腦很吃 CPU,桌機的 Chrome、Edge、Firefox 最順。手機可以看,但操作不方便。

模擬器是 v86(BSD-2-Clause,Fabian Hemmer 與貢獻者),BIOS 是 SeaBIOS(LGPL-3.0)。磁碟映像是 v86 專案預先安裝好的版本。各作業系統依各自的授權散布,原始碼連結在每台電腦的介紹裡。
